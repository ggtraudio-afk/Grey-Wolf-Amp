# 🐺 Grey Wolf Amp

**An All-in-One Guitar Amplifier by GGTR Audio**

Grey Wolf is a versatile guitar amp plugin designed to bring essential guitar processing tools together in one place.

From classic clean tones to high-gain sounds, Grey Wolf combines its own amplifier section with NAM profile support and additional built-in effects.

## Features

- **Amplifier:** Built-in guitar amplifier.
- **Drive:** Integrated overdrive section.
- **Noise Gate:** Built-in noise reduction.
- **Parametric EQ:** Apex EQF-2-inspired EQ with Bass, Mid and Treble controls.
- **Cabinet Simulation:** Built-in cab simulation with the option to disable it and use external cabinets.
- **NAM Support:** Load your own Neural Amp Modeler profiles for clean, crunch and high-gain tones.
- **Doubler / Twin Tracker:** Create wider and fuller guitar sounds.
- **Transpose:** Change guitar tuning without physically retuning your instrument.
- **Room:** Add room ambience directly within the plugin.

## NAM Profile Support

Grey Wolf supports NAM (Neural Amp Modeler) profiles, allowing you to use a wide variety of amplifier captures beyond the built-in amp.

## Built for Guitarists

Grey Wolf was developed around practical features that guitar players actually need, bringing multiple tools together without relying on several separate plugins.
